# 💰 Expense Tracker

A Python-based Expense Tracker application with a graphical user interface built using Tkinter and SQLite.

## ✨ Features

- Add daily expenses
- Select expense categories
- View all expenses
- Delete expenses
- Calculate total expenses
- Expense reports
- Category-wise spending charts
- Pie chart and bar chart
- SQLite database for storing expenses
- User-friendly Tkinter GUI

## 🛠️ Technologies Used

- Python
- Tkinter
- SQLite
- Matplotlib
